# Agent workflow

Follow brief sections 49 and 50. Inspect Git and persistent status, run existing tests, and confirm state before assigning work. Concurrent agents use isolated ignored .worktrees directories and dedicated branches; only the coordinator merges. Commit reviewed research before architecture.

Do not modify another agent's files, rewrite shared history, add secrets, or mark hardware tests passing from inference. Record exact evidence, source URLs/revisions, unknowns, and independent review. Use merge commits to retain workstream traceability. No remote messaging or publishing is authorized by this workflow.

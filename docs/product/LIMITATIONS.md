# Limitations

The app is still a launch skeleton: no camera pairing, Wi-Fi join, physical EasyConnect session, screen capture, TFT projection, reconnect or diagnostic export is available. Native simulator build/launch and host-only protocol tests pass. Synthetic H.264 video/receiver decode is implemented on the Gate 2 development branch under review; it is not wired into a usable phone mirroring workflow. Full-display/background capture, cellular coexistence and 450NK compatibility remain unverified. No continuous-session claim or alpha release exists. CAN/OBD, telemetry HUD, CarPlay, input injection, handlebar controls, audio, extra motorcycle models and production App Store release are outside scope.

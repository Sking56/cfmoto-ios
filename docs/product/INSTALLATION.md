# Installation

There is no downloadable iOS build or App Store release. Developers can obtain the source, open OpenCFMoto.xcodeproj on a Mac with an iOS 27+ SDK, select the OpenCFMoto scheme and an iOS 27+ simulator, then build/run. For device installation select your own development team and unique bundle identifier. These native steps have not yet been executed in this Windows workspace. See ../../README.md for portable checks and the Xcode verification script.

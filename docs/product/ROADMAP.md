# Roadmap

1. Gate 0: independently reviewed protocol, capture, network and licensing research.
2. Gate 1: tested protocol core and independent Dash Simulator handshake.
3. Gate 2: deterministic synthetic video to simulator.
4. Gate 3: real iPhone capture to simulator while navigation is foreground.
5. Gate 4: test pattern on a verified 450NK TFT.
6. Gate 5: full iPhone mirroring to TFT.
7. Gate 6: >=30 minutes, recovery, diagnostics, clean install and independent acceptance.

Waze, Apple Maps and Google Maps projection remain experimental until those checks pass.
